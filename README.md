# EcoEnergy(Unity, C#)

EcoEnergy is a Unity-based energy management simulation game focused on balancing energy production and consumption through a simple and progressive gameplay loop.

This repository is created as a **portfolio project** and is intentionally structured to showcase **gameplay and system-level programming skills**.

---

## Project Purpose

The main goal of this project is to demonstrate:
- Gameplay system design
- Resource and state management
- Clean and maintainable Unity C# code
- End-to-end completion of a playable project

The game challenges the player to maintain energy stability by managing different energy sources and consumption demands.

---

## Repository Scope

**Scripts Only Repository**

This repository intentionally contains **scripts only**.

This decision was made to:
- Keep the repository lightweight
- Avoid asset licensing issues
- Focus on code quality and architecture

A **playable build** is provided separately.

---

## Implemented Systems

- Game state management (start, running, fail states)
- Energy production and consumption logic
- Resource balancing system
- UI update and feedback logic
- Modular manager-based architecture
- Player input handling

---

## Technology Stack

- **Engine:** Unity
- **Language:** C#
- **Architecture:** Modular / Manager-based
- **Build Type:** Release Mono
